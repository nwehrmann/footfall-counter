# Library Footfall Counter

A shared tap counter for footfall in front of the library: people who go in, come out or walk past, counted per time slot.

- **Website:** https://nwehrmann.github.io/footfall-counter/
- **Hosting:** GitHub Pages serves the files in this repo.
- **Data:** a Supabase database stores the slots and counts (`setup.sql` creates it).

On a phone, open the link and choose "Add to Home Screen" to use it like an app.
